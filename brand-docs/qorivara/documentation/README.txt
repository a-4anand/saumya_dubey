USAGE

- Use transparent PNG files when SVG is not accepted.
- Use symbol-only square assets for profile images and circular avatar crops.
- Use website-header-light on light navigation backgrounds.
- Use website-header-dark on dark navigation backgrounds.
- Keep at least 0.25× the Q symbol width as clear space around standalone marks.
- Never stretch, outline, recolor, rotate, add effects, or change the Q/wordmark relationship.
- White and cream transparent assets are intentionally invisible on white viewers; place them on dark backgrounds.
